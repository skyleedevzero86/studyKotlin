# 소개
본 프로젝트는 Spring Boot 기반의 백엔드 서비스로, Azure OpenAI 서비스를 연동하여 문맥이 이어지는 대화형 AI 어시스턴트를 구현한 것입니다. 
또한 사전에 설정한 특정 문장을 통해 기업 정보, 개인 정보, AI 이름 등 일부 특수한 내용을 설명할 수 있는 기능도 제공합니다.
현재는 백엔드 서비스만 제공되며, 사용자가 필요에 따라 프론트엔드는 직접 구현해야 합니다。

# 프로젝트 설정
**이 프로젝트에는 다음 세 가지 설정이 필요합니다：** </br>
- application.yml -> Azure Key、MySQL、Redis
- ChatConstant.kt -> 본인이 원하는 **사전 정의 문장(프롬프트)**을 여기에 추가합니다.
- ChatHistoryService.kt -> 위에서 추가한 사전 정의 문장의 개수에 따라 index 값을 수정해야 합니다.
